How it works

Two painters that check each other's work.

CycleGAN needs no matched pairs. Give it a folder of photos and a folder of murals, and two generators learn to translate in both directions, while two critics try to tell real from fake.

01

Repaint the photo

Generator G(A→B), a 9-block ResNet, turns a Kerala photo into a mural-style image.

02

Judge it in patches

Discriminator D_B, a 70×70 PatchGAN, scores every patch: real mural texture or a fake?

03

Paint it back

G(B→A) turns the mural back into a photo. It must match the original, so content survives (cycle loss, λ = 10).

Photo A— G(A→B) →Mural B— G(B→A) →Photo A′ ≈ A
Three translations

One model design, three Kerala styles.

Each translation is trained as its own model on its own unpaired dataset, from the easiest to the showpiece.

Model card

What's under the hood.

GeneratorResNet encoder–decoder, 9 residual blocks, instance norm, reflection padding
Discriminator70×70 PatchGAN, LeakyReLU 0.2
LossesLeast-squares GAN + cycle consistency (λ = 10) + identity (λ = 5)
OptimiserAdam, lr 2e-4, β = (0.5, 0.999); constant for half the epochs, then linear decay to zero
StabilisersImage pool of 50 past fakes; random crop and horizontal flip
Resolution256 × 256, batch size 1
Training planAbout 100 epochs per translation on a free Colab or Kaggle T4 GPU
EvaluationFID with pytorch-fid, before/after grids, and a "real or generated?" survey
DemoGradio app on Hugging Face Spaces (upload a photo, pick a style)
Status: data collection and training in progress
Quick start

Train your own in four commands.

Collect two folders of unpaired images, let the prepare script clean and split them, then train. A Colab notebook in notebooks/ runs the same steps on a free GPU.

terminal
# get the code
git clone https://github.com/abhinavrenjithg-sys/KeralaGAN.git && cd KeralaGAN
pip install -r requirements.txt

# build a dataset from two raw folders
python scripts/prepare_dataset.py --a raw/summer --b raw/monsoon --name monsoon

# train (add --resume after a Colab disconnect)
python -m keralagan.train --data data/monsoon --epochs 100 --amp

# repaint your own photos
python -m keralagan.translate --ckpt checkpoints/monsoon/latest.pt --input photos/ --out results/
